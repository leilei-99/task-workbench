# 任务推进工作台

一个零依赖的单文件网页工作台：把工作内容按类别分成 A / B / C…，**做完一类才显示下一类**，每天自动重新开始，并把昨天没做完的单独留一个页签补做。

适合每日固定流程清单、分阶段检查表、按顺序推进的值班 / 巡检任务。

## 在线使用

本仓库是纯静态单页，开启 GitHub Pages（Source: `main` 分支 / 根目录）后即可直接在线访问，无需登录。

## 直接用

下载 `index.html`，用浏览器双击打开即可。**不需要安装、不需要构建、不需要服务器、不需要登录。**

## 三个页签

| 页签 | 作用 |
| --- | --- |
| 今日任务 | 只显示当前一类；逐项打勾，全部勾完自动解锁下一类；再点一次可取消；全部完成显示完成态 |
| 昨日未完成 | 按类别列出昨天没勾的任务（含未解锁类别），点一下标记补做；不影响今日进度 |
| 内容设置 | 编辑类别与任务内容，实时预览、格式校验 |

## 每天怎么重置

- 每天第一次打开 → 今日打勾清空，从第一类重新开始
- 昨天的进度和当时的内容会自动归档到「昨日未完成」
- 归档**只保留昨天一天**；隔天没打开就自动过期
- 昨天用旧内容做的记录不会因今天改了内容而错位（存的是内容快照）
- 勾错了可以再点一次取消；也可以点「重置今日」把当天全部清空重来

## 配置工作内容

在「内容设置」页按每行一类填写：

```text
A类任务：1、2、3
B类任务：1、2、3
C类任务：1、2、3
```

- 支持中文「：」或英文「:」
- 多个任务用中文顿号「、」分隔，不支持英文逗号
- 类别名不能重复，同一类别下的任务也不能重复
- 行顺序就是解锁顺序
- 保存后今日进度重置（昨日归档不受影响）

默认预置 A / B / C 三类各 3 项，打开就能直接试解锁效果。

## 数据存哪里

打勾记录存在浏览器 `localStorage`（键前缀 `wb_taskflow_`），**只在本机本浏览器有效**，不跨设备同步、不上传服务器。换浏览器或清理站点数据会清空进度。
